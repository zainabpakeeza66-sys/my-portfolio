# Zainab Pakeeza — Master's by Research Portfolio

GitHub Pages-ready static portfolio for Master's-by-Research and scholarship applications.

## Publish on GitHub Pages

1. Create a **public** GitHub repository, e.g. `zainab-pakeeza-portfolio`.
2. Upload **all contents of this folder** to the repository root.
3. Confirm that `index.html` is directly at the repository root and that `assets/` is beside it.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Choose **main** and **/(root)**, then **Save**.
7. GitHub will display your live Pages URL in the same section.

## Keep these paths unchanged

- `assets/images/` contains the portfolio images.
- `assets/evidence/` contains the research PDFs and Sweet Intake presentation.
- The HTML uses relative paths, so it works on a GitHub Pages project URL such as `https://USERNAME.github.io/REPOSITORY/`.
- No external CSS or JavaScript library is required.
- The Sweet Intake presentation is available as both PDF and PPTX.
